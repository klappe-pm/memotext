# Tutorials

Tutorials are lessons. Each one takes a reader who has not done the task before through it from start to finish, on one path, explaining only what that path needs. They exist so a newcomer succeeds at something real on the first try; they are not the place to look up an option or to understand a design, and they link out to the reference and explanation pages for that.

## Pages

- [Getting Started](getting-started.md): from an install to a probed library, a list of recordings and one transcript read both on the command line and from Python.
- [First Contribution](first-contribution.md): from a fresh clone to a passing test suite, a small change with its test, and a pull request.
