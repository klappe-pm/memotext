# How-To Guides

How-to guides are recipes. Each one solves a specific problem for a reader who already knows what Memotext is and wants the steps, with the minimum of explanation along the way. They assume more than a tutorial and promise less: a guide gets you to one outcome, and links to the reference pages for the details it skips.

## Use

- [Install](install.md): every supported way to install, upgrade and uninstall the command.
- [Read Transcripts from Python](read-transcripts-from-python.md): find the library, read recordings, handle errors and detect changed recordings from a script.
- [Troubleshooting](troubleshooting.md): symptoms matched to their causes and fixes.

## Contribute

- [Run the Tests](run-the-tests.md): the test suite, coverage, the lint and type checks, and how to run on Python 3.11.
- [Build a Synthetic Recording](build-a-synthetic-recording.md): make an `.m4a` fixture with a `tsrp` atom and a `manifest.plist` for a test, without a real recording.
- [Cut a Release](cut-a-release.md): publish a version to PyPI through trusted publishing.
