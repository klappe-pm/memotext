# how-to-guides

How-to guides are recipes. Each one solves a specific problem for a reader who already knows what voicememos is and wants the steps, with the minimum of explanation along the way. They assume more than a tutorial and promise less: a guide gets you to one outcome, and links to the reference pages for the details it skips.

## pages

- [install](install.md): every supported way to install, upgrade and uninstall the command.
- [troubleshooting](troubleshooting.md): symptoms matched to their causes and fixes.
- [read transcripts from python](read-transcripts-from-python.md): find the library, read recordings, handle errors and detect changed recordings from a script.
